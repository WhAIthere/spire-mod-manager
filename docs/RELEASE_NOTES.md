# 1.11.0 · 工坊合集、辅助订阅与增量更新

下载 `spire-mod-manager-1.11.0-windows-x64.zip`，完整解压后运行“尖塔模组管理器.exe”。支持 Windows 10/11 x64 和 Steam 版杀戮尖塔 I / II。升级前先退出旧版，保留原来的 `data` 目录。

- **工坊合集**支持导入链接或编号，按工坊 ID 合并已有项目。尚未下载的模组可以先留在清单里查看名称和封面。
- **塔二辅助订阅**支持按分组和搜索结果勾选。先预览名单，再确认交给已登录的 Steam 下载。
- **更新模组列表**增量扫描本地文件，只检查新增、文件有变化或上次未完成的工坊资料。右上角「选择更新项目」可单独更新本地文件、工坊名称或封面，也可一键全部更新。
- **资源状态与前置检查**可查看订阅、本地文件和可配置状态，检查已开启模组的前置，并补开本地已有且可明确匹配的依赖。
- **清单和备份**优先按工坊编号匹配模组，新导出的备份包使用包内相对路径，方便在其他安装目录恢复。
- **搜索与跳转**支持空格组合关键词、`+词` 添加备选条件、`-词` 排除结果。双击来源列可打开工坊页面或在资源管理器定位文件。

这是公开测试版。工坊封面需要 Steam 账号 API，旧版文件缓存可按需开启。源码构建、搜索语法和备份用法见 README。
