# 1.9.2 · 首次公开测试版

面向 Windows 10/11 x64、Steam 版杀戮尖塔 I / II。

## 下载与运行

普通用户下载 `spire-mod-manager-1.9.2-windows-x64.zip`，完整解压到可写目录，运行“尖塔模组管理器.exe”。无需安装 Python，无需安装包。不要只从 ZIP 拖出 EXE；旁边的 _internal 必须保留。系统需要 Microsoft Edge WebView2 Runtime 与 .NET Framework 4.8；Windows 10/11 通常已有，缺少时按 README 的官方链接安装。

源码使用者阅读 DEVELOPMENT.md；GitHub 自动生成的 Source code ZIP 不是 Windows 程序包。

## 功能

- 扫描本地和创意工坊模组，管理开关、昵称、分组、标签及开关方案。
- 表格／封面视图、日夜主题、搜索筛选、多选、撤销重做、分组拖放。
- 可选 Steam API 更新标题与封面，Key 可在本机加密保存。
- 可选保留模组历史文件、分包导出、导入并取出所需模组。

## 使用与限制

- 应用开关前关闭游戏；Steam 工坊开关功能需要 Steam 正常运行并登录相应账号。
- 修改后需“预览并应用”。备份默认关闭，开启后可能占用大量额外空间。
- Steam 或游戏更新可能影响适配；旧模组的游戏版本、依赖和兼容性需自行确认。
- 工坊标题和图片读取依赖 Steam 服务与本机网络；无 Key 时可以查询网页标题，自动补齐封面需要 Key。
- 目前主要在开发者机器及临时数据中验证，欢迎通过 Issues 提交复现步骤。日志、截图上传前请自行检查账号、个人路径等信息，并勿提交 API Key。
