# 1.10.0 · 模组清单与本地资源状态

支持 Windows 10/11 x64，Steam 版杀戮尖塔 I / II。下载 windows-x64.zip，完整解压后运行 EXE，无需安装 Python；保留 _internal。升级前关闭旧版，覆盖程序文件时保留自己的 data 目录。

## 本次更新

- 右上角省略号 →“模组清单：导入 / 导出”：分享编号、昵称、标签、分组顺序、开关草稿和方案，不带模组文件、个人路径、Key 或备份索引。
- 导入前预览本地匹配与缺失数量，默认合并，亦可选择采用清单信息；不移除其他模组，不直接应用到游戏。
- 尚未安装的项目保留为黄色“缺失”记录，可继续整理或打开创意工坊手动订阅；下载后更新列表自动重新匹配。状态标签不可手动删除，缺失记录可选中后从清单菜单移除。
- 顶部单独显示本地扫描状态、扫描时间提示及本地可用／列表数量。更新标题和封面不会冒充重新扫描本地。

## 当前范围

本版不自动订阅、不下载模组，不导入游戏文件，不根据清单版本号锁定或回退工坊版本。版本号仅供参考。清单支持本版导出的 JSON 格式；本地有多份无法唯一匹配的条目会保留为待确认的缺失项，不任意选一个版本。

本地可用表示已扫描到且可配置，不保证运行兼容；游戏版本和模组依赖仍需核对。备份默认关闭，使用方式见 README。
