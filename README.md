# 尖塔模组管理器

Windows 上的杀戮尖塔 1 / 2 模组整理工具：管理开关、昵称、分组、标签和开关方案，可选保留旧版文件并导出备份包。

作者：泉（WhAIthere）。

## 下载与运行

在 [GitHub Releases](https://github.com/WhAIthere/spire-mod-manager/releases) 下载文件名以 `-windows-x64.zip` 结尾的 Windows 包，完整解压到可写目录，双击“尖塔模组管理器.exe”。无需安装 Python，运行时请把 EXE 和旁边的 `_internal` 放在一起。

从旧版升级时，先关闭管理器，再用新版程序文件覆盖旧版，保留原来的 `data` 目录。

支持 Windows 10/11 x64 与 Steam 版游戏。应用开关时关闭游戏，Steam 工坊开关需要 Steam 正常运行并登录对应账号。

系统需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 和 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)。系统通常已有；缺少时从微软官方页面安装。本包不捆绑游戏、模组、封面或任何个人数据。

## 先这样用

1. 选择尖塔 I 或 II。找不到游戏或配置时，进入右上角省略号 → “路径与高级设置”确认路径。
2. 在列表调整开关，或用搜索、分组、标签批量整理。列表包含已安装但关闭的模组。
3. 点击“预览并应用”，确认修改，再启动游戏。列表开关在应用之前只是草稿。

“开关方案”只保存和载入勾选状态，不复制模组文件。新装了模组后，载入旧方案会默认关闭方案中没有记录的模组。

## 刷新和日志

- **更新模组列表**：增量扫描本地文件，只检查新增、文件有变化或上次未完成的工坊名称和封面。仅开启缓存时才保存文件副本。
- **选择更新项目**（右上角省略号）：可分别勾选本地文件、工坊名称和工坊封面。弹窗内的 **全部更新** 会扫描本地文件，并检查清单中所有工坊项目的名称与封面，包括尚未下载的模组。封面更新需要启用 Steam 账号 API。
- **日志**：查看当前任务进度、停止可中断的任务、阅读历史日志和扫描／依赖提示。

获取工坊信息需要网络；账号和获取方式在右上角省略号 → “Steam API 管理”里。没有 Steam API Key 时可以使用网页标题查询，封面补齐需要配置 Key。Key 可通过 Windows DPAPI 在本机加密保存，不会进入备份包。

## 备份是可选功能

**默认关闭。缓存模组文件可能额外占用数 GiB 甚至更多磁盘，不影响日常模组开关和整理。**

需要保留旧版时：首次“更新模组列表”选择是否保存缓存并记住；以后可在右上角省略号的“更新与备份设置”修改。备份包导入导出也在省略号里。

- 本地缓存是等待导出的模组版本；导出成功后会清理这份缓存。
- 备份包命名为 V导出次数.包号.zip，例如 V1.1.zip。每包约 512 MiB，单个大版本会独立成包。
- 可以上传网盘后删除本地包。管理器保留已导出记录，不会因此重复缓存。
- 恢复时，在详细信息中的“版本与备份记录”查出包号，只下载对应一包，通过文件选择框选中 ZIP 导入（任意位置），再选“取出模组文件”，不需要之前的整批包。
- 包可手动解压。每包携带识别所需信息，管理器内部也保留包号与版本对照；导出目录不另放外置清单。
- 恢复文件前关闭游戏和加载器。Steam 后续更新可能覆盖恢复的旧版；恢复模组文件不会回退游戏或存档。

双击“模组名称”打开详细信息；双击“版本”查看单个模组的历史版本和本机现有副本。历史分为“曾经记录但没有备份”“本地有备份”“已导出备份”，导出包移走后仍保留包号。关闭缓存也会记录以后扫描到的版本信息，但无法找回从未保存过的旧文件；这里不是工坊完整的发布历史。

有备份文件的历史版本可选择“回滚到此版本”：先校验备份，再强制备份当前同 ID 版本所在的完整模组包，最后将旧版安装到游戏 mods。回滚会替换本地 mods 中的同 ID 副本，保留工坊原文件，准备开关草稿供“预览并应用”。找不到已导出的包时需先导入对应 ZIP。多个模组共用同一安装目录、无法安全单独替换时会提示取出文件手动处理。塔一 ModTheSpire 可能优先采用同 ID 的新版工坊文件，恢复文件不保证能指定旧版；塔二应用时会检查所需工坊文件夹和重复 ID 冲突。此操作不回退游戏或存档。

移动管理器时保留 data 目录，里面有昵称、标签、方案和备份定位记录。不要将个人 data 或模组包放到公开源码仓库。

## 常用操作

- 昵称双击编辑；开关列切换模组。
- Ctrl / Shift 多选，Ctrl A 选择当前组；点击空白后 Ctrl A 选择所有组。
- 鼠标右键拖框选择；自定义分组可双击改名，左侧把手上下拖动排序。
- Ctrl Z 撤销，Ctrl Shift Z 重做；修改开关后仍需应用。
- 搜索栏右侧的“表格 / 封面”按钮切换浏览方式；分组排序、筛选结果批量开关在旁边的显示选项中。选中模组后显示快捷标签输入框，输入的标签会保留。
- 支持系统、日间和夜间主题。

## 分享模组清单

右上角省略号 →“模组清单：导入 / 导出”。清单只包含工坊编号、包内相对文件名、名称／昵称、版本参考、标签、分组顺序、期望开关及开关方案，不含游戏或模组文件、个人路径、Key 或历史备份索引。

导入前显示本地匹配和缺失数量。默认合并已有整理信息，也可选择采用清单内容；开关只改变草稿，仍需“预览并应用”。清单之外的模组会保留。黄色“缺失”为系统状态，下载完成后更新列表会重新匹配并保留整理信息。可打开创意工坊手动订阅，塔二也可使用下文的辅助订阅。

顶栏进度条显示清单总数、Steam 订阅状态、本地已扫描文件和可配置项目。点击进度条可查看各项数量，并手动刷新塔二的 Steam 订阅状态。可配置表示管理器可设置开关，运行兼容性取决于游戏版本和模组依赖。

## 工坊合集清单

顶部“从 Steam 订阅”接受模组或合集链接和编号，识别所属游戏后切换并显示预览。塔二可在导入后单独预览和确认订阅。只导入清单，不订阅、不下载、不改变现有开关；已有项目按工坊编号合并，缺失项下载后更新列表即可关联。支持嵌套合集和重复成员去重；重复导入增量合并，不自动移除旧成员。配置 Steam API Key 时优先用简体中文详情接口获取标题，未配置时使用公开详情接口。网络失败会保留原清单。

在“合集分组”中查看来源，同一模组可出现在多个合集下，操作同一份开关。合集来源与手动标签独立；列表显示菜单提供“全部／仅本地已有／仅本地缺失”。工坊参考标签映射尚未启用，因此标签列始终只包含手动标签和“缺失”标记。合集来源随模组清单导出导入。尚未下载的项目仅显示工坊更新时间，不能据此认定内部版本号或兼容性。

想从空清单演示导入，可给 EXE 加上 `--collection-demo` 参数，或运行 `python web_app.py --collection-demo`。演示在临时清单中联网查询工坊资料，仅限体验清单整理流程。

## 辅助订阅（尖塔 II）

选中缺失的工坊模组，省略号 → 模组清单 →“订阅选中缺失模组”。需要 Steam 已运行并登录、拥有游戏，且管理器中的塔二目录和账号配置正确。先只读检查并预览名单，再点击“订阅并交给 Steam 下载”。Steam 会自动安排下载，可能立即消耗网络和磁盘；无需 Steam 密码或 Cookie，订阅通过客户端完成。

每次最多 50 项；已订阅的跳过。确认绑定本次账号和名单，超过五分钟或状态变化需重新预览。结果未确认时停止后续提交，不自动重试或退订。停止任务只阻止后续请求，已经提交的订阅／下载不会自动撤销。下载完成后更新模组列表并核对开关；管理器不自动启动游戏或修改开关，Steam 新订阅项目仍可能按游戏加载器规则参与加载。塔一暂用工坊网页订阅，空白清单体验禁止真实订阅。

## 辅助订阅视图与搜索

顶部“辅助订阅”切换为尚未订阅的工坊清单，保留分组、表格／封面和筛选。左列是待订阅勾选，不是游戏开关，点击不会立即订阅。支持组内勾选、按搜索结果全勾选、Ctrl/Shift 多选后“勾选选中项”、空格切换勾选，最后点击“订阅已勾选”预览并确认。返回模组管理会清空本次勾选，不改变游戏开关。手动在 Steam 订阅后可点“刷新订阅状态”；已订阅但尚未下载完成的项目也不显示在此视图。空白演示可体验勾选，但禁止真实提交。

搜索默认跨昵称、模组名称、文件路径、标签、分组、版本等字段，不区分大小写。空格是 AND；`+词` 开始一个 OR 分支，分支内空格仍是 AND；`-词` 全局排除，优先排除全部分支。示例：`角色 美化 +皮肤 -测试` 等于 `(角色 AND 美化 OR 皮肤) AND NOT 测试`。`角色 +皮肤 高清` 等于 `角色 OR (皮肤 AND 高清)`。引号保留带空格词组，如 `"Some Name"`。保留 `tag:完整标签`、`file:文件名`、`version:版本` 等字段搜索，`collection:合集名称` 可查合集来源；tag 字段精确匹配完整标签，普通关键词仍是子串匹配。
